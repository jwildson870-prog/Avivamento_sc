# Cloudflare

## Objetivo
Usar o Cloudflare para DNS e HTTPS do domínio.

## Fluxo
```text
Domínio
→ Cloudflare DNS
→ Render
→ Aplicação Flask
```

## Regras
- Manter HTTPS em produção.
- Não colocar segredos em DNS ou código público.
- Registrar alterações importantes de domínio aqui.

## Domínio
O domínio oficial da igreja será definido posteriormente.
