# Pastores

## Objetivo
Manter uma área pública para apresentar os pastores da igreja.

## Informações
Cada pastor pode possuir:
- nome;
- cargo;
- foto;
- biografia;
- status de publicação.

## Administração
O administrador poderá, conforme a implementação:
- adicionar pastor;
- editar pastor;
- excluir pastor;
- alterar foto;
- publicar ou ocultar informações.

## Privacidade
Somente informações destinadas à apresentação pública devem aparecer para visitantes.

## Atualização
Mudanças nos campos ou no fluxo administrativo devem ser registradas aqui.
