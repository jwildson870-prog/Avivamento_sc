# Automação

## Objetivo
Documentar tarefas automáticas do projeto.

## Automação de deploy
O fluxo recomendado é:

```text
Alteração
→ Git
→ GitHub
→ Render
→ Deploy
→ Teste
```

## Outras automações
Este documento deve registrar futuramente tarefas como:
- limpeza de arquivos temporários;
- migrações de banco;
- backups;
- rotinas administrativas;
- notificações, se forem implementadas.

## Regra
Não considerar uma automação implementada apenas porque ela foi planejada. Registrar somente o que estiver realmente configurado.
