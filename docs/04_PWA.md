# PWA

## Objetivo
Permitir que o site Avivamento seja instalado como aplicativo no celular e em navegadores compatíveis.

## Componentes
- `manifest.json`: nome, ícones, cores e comportamento de instalação.
- Service Worker: cache e recursos necessários ao funcionamento do PWA.
- Ícones: versões adequadas para os tamanhos exigidos pelo navegador.

## Identidade
A imagem de referência enviada para o projeto deve orientar o ícone do Avivamento, com a versão visual preta solicitada.

## Teste
1. Publicar o site em HTTPS.
2. Abrir no navegador.
3. Verificar o manifesto.
4. Verificar os ícones.
5. Verificar a instalação.
6. Testar abertura após instalação.

## Atualização
Qualquer alteração de manifesto, ícones, cache ou estratégia offline deve ser registrada aqui.
