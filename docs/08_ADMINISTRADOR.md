# Administrador

## Objetivo
Documentar a área administrativa.

## Acesso
A área administrativa deve ser protegida por autorização no backend.

## Funções
Conforme implementadas, podem incluir:
- gerenciar biografia da igreja;
- gerenciar pastores;
- gerenciar usuários;
- atualizar conteúdos;
- visualizar informações administrativas.

## Regra de segurança
Nunca confiar somente no frontend para verificar se alguém é administrador.

## Evolução
Toda nova função administrativa deve ser adicionada neste README, com sua permissão e impacto.
