# GitHub

## Objetivo
Usar o GitHub como repositório oficial do código.

## Fluxo básico
```bash
git add .
git commit -m "tipo: descrição"
git push origin main
```

## Convenção de commit
Preferir mensagens claras, por exemplo:
- `feat:` nova funcionalidade;
- `fix:` correção;
- `style:` alteração visual;
- `docs:` documentação;
- `refactor:` reorganização interna.

## Regra
Quando uma mudança afetar documentação, atualizar os READMEs no mesmo commit.
